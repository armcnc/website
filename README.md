## Basic Requirements

Your device should meet the following basic requirements.

```shell
NodeJS:         ≥v22.15.0
Yarn:           ≥1.22.22
```

## Initialization

Initialize the project through the following method

```shell
yarn
```

```shell
yarn dev
```

## Compile Build

Compile and build the project through the following methods

```shell
yarn build
```
